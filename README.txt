UPLOAD AUF GITHUB
1. ZIP-Datei auf dem Mac doppelt anklicken und entpacken.
2. Öffne den entpackten Ordner. Hochgeladen wird der INHALT dieses Ordners,
   nicht die ZIP-Datei und nicht der übergeordnete Ordner.
3. Öffne:
   https://github.com/zahnklar-leichterklaert/zahnklar
4. Klicke im Bereich „Code“ auf „Add file“ und anschließend auf „Upload files“.
5. Ziehe alle enthaltenen Dateien und Ordner in das Upload-Feld. Dazu gehören
   insbesondere index.html, style.css, site.js, der Ordner assets und der Ordner en.
6. Warte, bis GitHub alle Dateien anzeigt.
7. Trage als Commit-Nachricht zum Beispiel ein:
   Zweisprachige Zahnklar-Website hinzufügen
8. Klicke auf „Commit changes“.
9. Warte etwa 1–3 Minuten auf die Veröffentlichung.
10. Prüfe anschließend:
    Deutsch: https://zahnklar-leichterklaert.github.io/zahnklar/
    Englisch: https://zahnklar-leichterklaert.github.io/zahnklar/en/
11. Falls noch die alte Version angezeigt wird, lade mit Cmd + Shift + R neu.

WICHTIG
- Die ZIP-Datei selbst nicht in GitHub hochladen.
